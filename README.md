# 🚀 CRUD em Flask e Python

Uma aplicação web simples para gerenciamento de usuários (CRUD: Criar, Ler, Atualizar e Deletar) desenvolvida com Python, Flask e HTML.

---

## 🛠️ Tecnologias Utilizadas

- **Python** (Backend)
- **Flask** (Micro-framework web)
- **HTML5 / CSS** (Frontend / Interface visual)

---

## 📌 Funcionalidades

- Lista de usuários cadastrados
- Cadastro de novos usuários (Nome e Idade)
- Atualização de dados de usuários existentes
- Remoção de usuários

---
